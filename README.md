# Sleep Toggle Menu

MacBookの強制スリープを許可するかどうかを、macOSのメニューバーから確認して切り替えられる小さなアプリ。

macOS 13以降で動作する。

## 表示と操作

- `🔥 0:59` は色つきの炎と残り時間の表示で、`SleepDisabled 1` の状態を示す。蓋を閉じてもスリープせず、残り時間が0になると自動で `SleepDisabled 0` に戻る。
- 中が抜けた白い炎のアイコンは `SleepDisabled 0` の状態を示す。蓋を閉じると通常どおりスリープする。
- 左クリックすると、スリープ可能なら1時間だけ起動維持にし、起動維持中ならすぐ通常に戻す。
- 右クリックすると、現在の状態と戻る時刻、1時間／2時間／6時間の起動維持（起動維持中は「いまから◯時間に延長」）、通常へ戻す、アプリ終了を表示する。

状態は3秒ごととMacの復帰時に `/usr/bin/pmset -g` から読み直す。アプリの内部状態ではなく、OSの実際の設定を正として表示する。

### 自動で戻す仕組み

起動維持のまま紛失したときにスリープしない状態が続かないよう、必ず期限を付ける。

- 期限は UserDefaults（`com.minorun365.sleep-toggle-menu` の `keepAwakeDeadline`）に保存し、アプリやMacを再起動しても引き継ぐ。起動時に期限を過ぎていれば、その場で戻す。
- 経過時間は実時間で数え、スリープしていた時間も経過に含む。
- ターミナルで `pmset` を打つなど、期限のない起動維持を見つけたら、その時点から1時間の期限を付ける。
- 「終了」を選ぶと、スリープ可能な状態に戻してから終わる。

## インストール

```bash
./Scripts/install.sh
```

初回だけ管理者認証が必要になる。パスワードなしで許可するのは、次の2つの操作に限る。

```text
/usr/local/libexec/sleep-toggle-helper 0
/usr/local/libexec/sleep-toggle-helper 1
```

ヘルパーは `root:wheel`、モード `0755` で配置するため、一般ユーザーは内容を書き換えられない。`pmset` 全体や任意のコマンドは許可していない。

アプリは `~/Applications/SleepToggleMenu.app` に配置され、LaunchAgentでログイン時に自動起動する。

## アンインストール

```bash
./Scripts/uninstall.sh
```

スリープを許可する状態に戻してから、アプリ、LaunchAgent、ヘルパー、限定したsudoersの設定を削除する。

## 注意

`pmset disablesleep` はmacOSの `pmset` マニュアルに記載されていないため、macOSの更新後は表示と実際に蓋を閉じたときの動作を再確認する。

起動維持のまま鞄やケースに入れない。蓋を閉じても処理が続くため、発熱とバッテリー消費につながる。移動後はメニューバーの表示を確認し、白い炎に戻す。

自動で戻す仕組みは、アプリが動いている間だけ働く。アプリを強制終了したまま起動維持にしていると、次にアプリが起動するまで戻らない。
